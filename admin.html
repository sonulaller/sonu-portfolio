Security

Password kabhi plain text me store nahi hota — Supabase Auth use hota hai jo password ko server side hash kar ke rakhta hai. Reset code bhi seedha Supabase verify karta hai, hum usse kabhi database me likhte hi nahi.

Tips: 12+ characters ka strong password use karo, aur kisi ke saath share mat karo.
